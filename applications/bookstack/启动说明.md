# BookStack 启动说明

## 依赖

Node.js >=22.12、npm，以及在目标机器安装的前后端依赖（含开发依赖）。

脚本只检查依赖，缺失时提示并中断，不下载或安装依赖。应用文件夹可独立分发。

## 启动

在本应用目录打开终端。

Windows PowerShell：

```powershell
.\start.bat
```

Windows 命令提示符：`start.bat`。

Linux / macOS Terminal：

```sh
sh start.sh
```

`sh deploy.sh` 也会调用相同入口，不会自动安装依赖。

## 自动寻找端口

默认从 **3000–3999** 按顺序寻找空闲端口，不再为应用写死端口。控制台打印实际访问地址，请以该地址为准。多个应用可以同时启动。

自定义检索范围：

```powershell
.\start.bat --port-range 4100-4199
```

```sh
sh start.sh --port-range 4100-4199
```

默认 `--port auto`。可以用 `--port 4108` 指定固定端口；如果该端口不可用则报错，不会悄悄改用其他端口。整个范围无可用端口时提示并退出。若检查后端口被其他进程抢占，自动模式会继续尝试下一个端口。

也支持环境变量 PORT_RANGE、PORT、HOST；命令行参数优先。已有 PORT 环境变量会指定固定端口，用 `--port auto` 可覆盖它。范围必须位于 1–65535 且起点不大于终点。

默认 HOST 为 127.0.0.1。需要局域网访问时可显式指定 `--host 0.0.0.0`。

## 停止和异常恢复

脚本前台运行，按 Ctrl+C 正常停止。配置错误、依赖缺失、启动失败或应用异常退出时，会按当前系统打印手动运行命令；已选定端口会带入提示。依赖缺失时先由用户自行准备。启动器被强制杀死、终端强制关闭或断电时可能无法打印提示。

检查依赖而不启动：`node start.cjs --check-deps`。

## 首次依赖准备及构建

由用户在目标机器的应用目录自行执行（PowerShell 可将 npm 改为 npm.cmd）：

```sh
npm ci --include=dev --include=optional
```

不要分发本机 node_modules，SQLite 原生模块与操作系统和 Node 版本有关。

启动器默认执行 `npm run build`，成功后运行 `backend/dist/server.js`。构建失败会中断并给出手动命令。源码未变化且已构建时可追加 `--skip-build`。端口检索在构建之后进行。

启动脚本不清空已有数据，也不修复业务或页面缺陷。Windows 和 Git Bash 的启动路径已通过本地检查；原生 Linux/macOS 尚未实测。
