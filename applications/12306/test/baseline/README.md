# Existing Baseline Tests

These are the original ARC-Bench test sources for this application, copied with their helpers and fixtures so you can check whether your proposed tests add new coverage.

Read the relevant `REQ-*.spec.ts` files together with `helpers.ts`, any fixtures, and `../../requirements/requirements.yaml`. These files are reference material for the exercise; the application launcher does not run them. Running them separately requires Playwright and a suitable test configuration and base URL, which are not included here.

Do not edit the baseline files in your submission. Place new tests and evidence in the sibling `../team-<ID>/` directory.
